# Great White Planet 安装步骤说明

**本地知识管理与 AI 辅助学习** · 版本 1.0.0 · 适用于 Windows 11

> **结论先说**：不需要预先安装 Python，不需要管理员权限，不需要联网。
> 解压 → 双击 → 选位置 → 点「开始安装」，约 5 秒完成。

---

## 一、安装前的准备

### 1. 系统要求

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows 11（Windows 10 21H2 及以上也可） |
| 架构 | 64 位（x64） |
| 磁盘空间 | 约 400 MB（程序 135 MB + 数据另计） |
| 内存 | 建议 4 GB 以上 |
| 权限 | **普通用户即可**，不需要管理员 |
| 网络 | 不需要。AI 功能要用时才需要联网 |
| 其它 | **不需要**预装 Python、不需要任何运行库 |

### 2. 解压安装包

安装包是一个 zip，请**完整解压**到任意文件夹后再运行 —— 不要只把
`安装 Great White Planet.exe` 单独拖出来，它旁边的 `_internal` 目录和
`payload.zip` 是必需的。

解压后应当看到：

```
Great White Planet 安装包\
├─ 安装 Great White Planet.exe     ← 双击这个
├─ payload.zip                     ← 软件本体（必须留着）
├─ 使用说明（先读我）.txt
└─ _internal\                      ← 安装程序的运行库（必须留着）
```

> **提示**：建议解压到桌面或「下载」文件夹，不要直接在压缩软件窗口里双击运行。

### 3. 安全软件提示

安装包**未做数字签名**，个别安全软件会拦未签名的程序，表现为双击没反应、
或弹出「已阻止」提示。若遇到：

1. 打开安全软件的「隔离区 / 拦截记录」，看是否有本安装包；
2. 把**解压后的整个文件夹**加入白名单（不是只加那一个 exe）；
3. 重新双击运行。

## 二、逐步安装

### 第 1 步：双击安装程序

双击 **安装 Great White Planet.exe**，会出现下面的界面：

![安装程序界面](installer_shots/01_welcome.png)

界面上有三个部分：

| 位置 | 说明 |
| --- | --- |
| **安装位置** | 默认 `C:\Users\<你的用户名>\AppData\Local\Programs\Great White Planet`；点「浏览…」可改 |
| **快捷方式** | 「创建桌面快捷方式」「创建开始菜单项」，默认都勾选，可按需取消 |
| **进度条** | 显示「正在安装 x/y」与当前文件名 |

### 第 2 步：确认安装位置（可选）

不改就用默认位置 —— 它在你的用户目录下，**不需要管理员权限**，也最不容易
出权限问题。想改的话：

* 点「**浏览…**」选一个文件夹；
* 会自动在该文件夹下再建一层 `Great White Planet` 子目录；
* 想装到 `D:\` 之类的其它盘，选到 `D:\` 即可，最终位置是
  `D:\Great White Planet`。

> **要不要装到 `C:\Program Files`？** 可以，但**需要管理员权限** ——
> 软件要把数据（科目、笔记、配置）写在安装目录下的 `data` 里。
> 除非你有特别理由，否则建议用默认位置或装到 D 盘等用户可写的位置。

### 第 3 步：点「开始安装」

点「**开始安装**」，进度条开始走动，状态栏显示正在解压哪个文件。
整个过程约 **5 秒**（视磁盘速度）。

如果目标目录里已经有文件，会先弹窗询问：

> 这个目录不是空的。继续安装会覆盖同名文件（用户数据 data 不会被覆盖）。继续吗？

* **新装**：选「是」；
* **升级**：也选「是」—— `data` 目录不会被动，你的资料保留。

### 第 4 步：完成

安装完成后弹窗提示装到了哪里、创建了哪些快捷方式，并询问是否立即启动。
选「是」就会直接打开软件。

## 三、验证安装成功

### 1. 看目录

安装目录里应当有这些内容：

```
Great White Planet\
├─ Great White Planet.exe          ← 主程序
├─ _internal\                      ← 自带的运行环境（Python + 各种库）
├─ Document\                       ← 说明书：功能说明 / 设计思想 / 使用说明 / 简要说明书
├─ 卸载 Great White Planet.exe      ← 卸载程序
├─ uninstall.json                  ← 安装记录
└─ data\                           ← 首次启动后才会出现
   ├─ user data\subjects\          ← 你的科目放在这里
   └─ else data\                   ← 配置、日志、聊天记录、缓存
```

### 2. 启动程序

双击桌面快捷方式或安装目录里的 `Great White Planet.exe`。
正常启动后应当看到主窗口，标题为
**「Great White Planet — 本地知识管理与 AI 辅助学习」**，
首页提示「双击进入科目…」并显示「＋ 新建科目」「＋ 新建收纳箱」。

首次启动会自动生成 `data` 目录和默认配置，**这是正常的**。

### 3. 出问题时看日志

如果窗口没出现或一闪而过，打开：

```
<安装目录>\data\else data\logs\
```

* `gwp.log` —— 运行日志，正常启动应能看到「预扫描完成」；
* `startup_error.log` —— **只有启动失败时才产生**。这个文件存在，
  说明启动过程中出错了，里面有完整的错误堆栈。

## 四、常见安装报错与处理

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 双击**完全没反应** | 被安全软件拦截；或没解压，直接在压缩包里运行 | 把解压后的整个文件夹加白名单；确认是从解压出来的文件夹里运行 |
| 弹窗「操作已被**取消**」 | 同上，被安全机制阻断 | 同上 |
| 提示「**目录非空**」 | 目标目录已有文件 | 新装或升级都选「是」；`data` 不会被覆盖 |
| 提示「**找不到内置的软件数据**」 | `payload.zip` 被删或没一起解压 | 重新完整解压安装包 |
| 装到 `C:\Program Files` 后**打不开**或存不了数据 | 该目录需要管理员权限才能写入 | 改装到默认位置或 D 盘；或把安装目录的写权限给当前用户 |
| 启动后**窗口空白/闪退** | 显卡驱动或显示环境异常 | 看 `startup_error.log`；更新显卡驱动；确认是 64 位 Windows |
| 提示「**已经有一个窗口在运行**」 | 软件限制同一份数据只开一个主窗口 | 切到已有窗口；若在另一个虚拟桌面，弹窗里有「切到那个桌面」按钮 |
| 卸载后**资料还在** | 这是**刻意设计** | 卸载不动 `data`。要彻底清理，手动删掉整个安装文件夹 |

## 五、安装之后

### 卸载

开始菜单 → **Great White Planet** →「**卸载 Great White Planet**」。

卸载会删除程序文件与快捷方式，**但不会动 `data` 目录** —— 你的科目、笔记、
日记都还在。要彻底清理，卸载完再手动删除整个安装文件夹。

### 升级到新版本

1. 直接把新版本的 zip 完整解压，得到新的安装程序；
2. 双击运行，**安装位置选成和原来一样**；
3. 提示「目录非空」时选「是」。

`data` 目录不会被覆盖，资料完整保留。装完打开软件确认科目都在即可。

### 换一台电脑

1. 在新电脑上照本文装好软件，**先启动一次**让它生成 `data` 目录，然后关闭；
2. 把老电脑安装目录下的整个 `data` 文件夹复制过来覆盖；
3. 重新启动，科目、笔记、日记都会在。

> AI 的 API Key 也存在 `data\else data\secrets.json` 里，会一起带过去。
> 如果不希望带过去，复制时排除这个文件即可，到新电脑上重新填。

## 六、还需要知道的

* **完全离线可用**：不配置 AI 也能正常使用整理、检索、导出等全部本地功能；
* **数据就是普通文件**：`data\user data\subjects` 下是普通文件夹，
  用资源管理器直接就能打开、复制、备份，不加密、不打包成数据库；
* **自带运行环境**：`_internal` 里是 Python 运行时与所有依赖库，
  所以目标电脑上没装过 Python 也能跑；
* **一份数据一个窗口**：同一份数据只允许一个主窗口，避免两端同时写坏数据。

更多内容见安装目录 `Document\` 下的：

* 《Great White Planet 简要说明书》—— 五分钟上手
* 《Great White Planet 功能说明》—— 逐项功能细节
* 《Great White Planet 设计思想》—— 目录结构与分层设计
* 《Great White Planet 使用说明》—— 按场景的操作步骤
