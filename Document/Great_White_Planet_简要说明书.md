# Great White Planet 简要说明书

**本地知识管理与 AI 辅助学习** · 版本 1.0.0 · 适用于 Windows 11

---

## 一、这是什么

Great White Planet 是一个**完全离线可用**的学习资料管理器。它把你在各个科目下的
教材、笔记、易错题、作业统一管起来，并在你愿意的时候调用 AI 帮你把零散资料
整合成一份有条理的学习文档。

设计上的两条底线：

* **你的资料就是普通文件夹里的普通文件** —— 不加密、不打包成数据库。
  用资源管理器直接就能打开、复制、备份；
* **AI 是可选的** —— 不配置任何 AI 也能完整使用整理、检索、导出功能。

## 二、安装

**不需要预先安装 Python，也不需要配置任何环境变量。** 软件自带完整的
Python 运行时与全部依赖库，在一台从没装过 Python 的 Windows 11 上照样直接运行。

1. 双击 **安装 Great White Planet.exe**；
2. 选择安装位置（默认 `%LOCALAPPDATA%\Programs\Great White Planet`，
   普通用户即可安装，**不需要管理员权限**）；
3. 勾选是否创建桌面 / 开始菜单快捷方式，点「开始安装」；
4. 安装完成后可直接启动。

> **安装包内不含任何用户数据。** 首次启动会在安装目录下自动创建：
>
> ```
> Great White Planet\
> ├─ Great White Planet.exe     ← 主程序
> ├─ _internal\                 ← 自带的运行环境（Python + 库，请勿手改）
> ├─ Document\                  ← 功能说明 / 设计思想 / 使用说明 / 本说明书
> └─ data\                      ← 你的数据（首次启动后出现）
>    ├─ user data\
>    │  └─ subjects\            ← 你建的科目都在这里
>    └─ else data\              ← 配置、日志、聊天记录、缓存
> ```

**卸载**：开始菜单 →「卸载 Great White Planet」。卸载会删除程序文件，
**但不会动 `data` 目录**，你的资料不会被删。要彻底清理请手动删除整个文件夹。

## 三、五分钟上手

### 1. 建一个科目

首页点「**＋ 新建科目**」，填名字、选类型：

| 类型 | 用途 |
| --- | --- |
| **自学课** | 自己啃的科目。有「练习」目录，**不参与 AI 总结** |
| **校修课** | 学校课程。有「作业」目录，**不参与 AI 总结** |
| **日记** | 按天记录。有「AI 思想总结」「AI 日记」两套生成功能 |

名字会成为文件夹名，类型建好后不能改（目录结构已按类型生成）。

### 2. 建一本书目

双击科目卡片 →「＋ 新建书目」。书目内部固定有这些目录：

```
book（教材） · error-prone（易错题） · notebook（笔记）
```

**参与 AI 总结的是「易错题」和「笔记」**，教材与练习/作业不参与。

### 3. 放资料进去

进入书目 → 点「**导入文件**」把文件复制进来（原文件不动），
或直接把文件拖进对应目录。

也可以点「新建 Markdown」在笔记里直接写。

### 4. 用 AI 整理（可选）

点「**生成总结**」→ AI 读笔记与易错题，产出一份 `summary` 文档。

> **前提**：需要先配置 AI。见下一节。

## 四、配置 AI（可选）

软件支持多家 AI，配置都在「设置」里，**只存在本机**。

### DeepSeek（推荐）

1. 到 `platform.deepseek.com` 注册并创建 API Key；
2. 软件里「设置 → AI → DeepSeek」，粘贴 Key，点「测试连接」；
3. 右上角会显示当前 AI。

### 其它

* 任何 **OpenAI 兼容**接口（填 Base URL + Key + 模型名）；
* **本地命令行**（如已装 ollama）—— 完全离线；
* 可配置多个提供方，主用不可用时自动切到备用。

> Key 保存在 `data\else data\secrets.json`，**不会**写进任何导出文件。
> 每次生成文档前会自动备份上一版到 `data\else data\summary_backup`。

## 五、常用操作

| 想做的事 | 怎么做 |
| --- | --- |
| 打开科目 / 书目 | **双击**卡片 |
| 重命名、换图、换色、删除 | **右键**卡片 |
| 调整顺序 | **拖动**卡片（箱子可和科目交替排列） |
| 把科目收进箱子 | 拖科目到**收纳箱卡片**上 |
| 把科目拿出来 | **右键科目** →「移出收纳箱」 |
| 新建收纳箱 | 首页「＋ 新建收纳箱」 |
| 进 / 出收纳箱 | **单击**箱子展开；「✕ 关闭收纳箱」退出 |
| 搜索 | 顶部搜索框 |
| 换背景图 | 菜单「查看 → 更改背景」 |
| 导出 PDF | 书目页「导出 PDF」（可加页码、选页码范围） |
| 看说明书 | 菜单「帮助」 |

### 收纳箱是什么

收纳箱只是**分组记录**，**不搬动任何文件** —— 科目还在原来的位置。
所以「删除收纳箱」不会删掉科目，箱内科目会回到最外层。

### 日记怎么用

进入日记科目 →「我的日记」标签写下当天内容 → 顶部两个按钮：

* **生成思想总结** —— 归纳这段日子的主题、情绪走势、想法的变化；
* **生成日记** —— 把所有日记按日期合并成格式统一的一篇。

结果分别出现在「AI 思想总结」和「AI 日记」标签里。

## 六、常见问题

**Q：需要先装 Python 吗？**
不需要。软件自带完整的 Python 运行时与全部依赖库，
在一台**从没装过 Python** 的 Windows 11 上可以直接运行。
（这一点做过实测：把开发机上已安装的 Python 目录整体改名藏起来后，
安装好的软件依然正常启动。）

**Q：数据存在哪？换电脑怎么带走？**
整份资料就在 `data\user data\subjects` 里，普通文件夹。
整个 `data` 目录复制走即可，在新机器上覆盖同名目录。

**Q：能同时开两个窗口吗？**
不能。同一份数据只允许一个主窗口，第二次启动会提示（含「切到那个桌面」按钮，
应对 Win11 多桌面）。

**Q：AI 报错 / 生成失败？**
先看「工具 → 依赖自检」；再确认 Key 与网络。生成失败**不会影响已有文件**。

**Q：软件打不开怎么办？**
看 `data\else data\logs\` 下的日志；启动失败还会额外写 `startup_error.log`。

**Q：卸载会删我的资料吗？**
不会。卸载只删程序文件，`data` 目录保留。

* **单实例**：一份数据一个窗口，避免两端同时写导致数据错乱；
* **版本管理**：每次生成总结前自动备份，可在书目页「版本管理」里恢复；

* **背景图**：`data\else data\background` 存放候选背景，更换时**不删旧图**。
