# Great White Planet 使用说明

> 软件「帮助 → 使用说明」会打开本文件。
> 当前版本：**v1.0.0**

---

## 一、第一次使用（约 3 分钟）

1. **启动**：双击桌面上的「Great White Planet」快捷方式。
   如果没反应，用 `D:\Great White Planet\code\启动 Great White Planet（调试）.bat` 启动，
   控制台会显示具体原因（也可看 `data\else data\logs\startup_error.log`）。

2. **新建科目**：首页右上角「＋ 新建科目」，输入名称（例如「高等代数」），
   并**选择类型**：

   | 类型 | 什么时候选 |
   | --- | --- |
   | **自学课** | 自己找资料学（默认）。标签是「练习」而不是「作业」 |
   | **校修课** | 学校开设、跟着老师上的课。标签是「作业」 |
   | **日记** | 按天记录。会自动建好 `MyBook` 与 `AI summary`/`AI diary`/`my diary`/`else diary`；顶部有两个按钮：「生成思想总结」和「生成日记」 |

   这个名字会成为文件夹名，建议用中文短名。
   类型建好之后**可以再改**：自学课与校修课可以互相切换
   （两者目录结构相同，切换不会动任何文件）；
   日记与普通科目之间不能切换（结构差别太大）。

   日记的用法：把每天写的东西放进「**我的日记**」标签，然后

   * 点「**生成思想总结**」→ 归纳你这段日子的主题、情绪走势、想法的变化；
   * 点「**生成日记**」→ 把所有日记按日期合并成格式统一的一篇。结果分别在
     「AI 思想总结」和「AI 日记」两个标签里。

3. **新建书目**：点进科目，点「＋ 新建书目」（例如「数学分析」）。
   软件会自动创建 `Introduct.md`、`book`、`error-prone`、`notebook`、
   `homework`（自学课显示为「练习」）、`others`（「其它文件」）。

   > 书目页的**标题栏只显示书名**，每个栏目有多少条内容直接标在**标签上**
   > （「笔记 3」「易错题 1」「全部条目 6」）；数量为 0 的栏目不显示数字，
   > 免得一排 `0` 看着乱。

4. **导入资料**：在书目页切到「笔记」标签，点「导入文件…」，
   或者直接把文件从资源管理器**拖进窗口**。
   易错题放进「易错题」标签，作业放进「作业」标签，
   教材放进「教材」标签（**教材与作业都不参与总结**）。

   其它不好归类的东西（老师发的课件、拍的照片、参考文档）放进
   「**其它文件**」标签 —— 它**不参与 AI 总结**，而且可以在里面
   **右键新建文件夹**按章节或来源分层整理。

   > **拖到哪一层就传进哪一层**。进了某个文件夹（标题会显示
   > `书目名 › others › 第一章`）再拖文件，文件就进那个文件夹；
   > 拖的时候标签条会提示「拖到这里 → others / 第一章」。
   > 想要更省事：**直接把文件拖到某个文件夹的那一行上**，
   > 或者右键文件夹 →「上传文件到「xxx」…」。

5. **把一堆照片变成文字**（拍的黑板、扫描的讲义、PPT 截图）：
   在那个文件夹里点菜单「工具 → **图片提取为 Markdown…**」
   （或右键文件夹 →「提取「xxx」里的图片…」），
   然后点「**全部提取**」。它会逐张把图片送进 AI 转写成文字，
   最后合成一份 `xxx_图片提取_日期.md` 放在同一个文件夹里。

   * 每一张都会弹窗让你**把 AI 的回答粘回来**
     （图片和提示词已经自动进了剪贴板，你只要在网页里 Ctrl+V 两次）；
   * **看不清的直接留空、点「跳过这一张」就行** ——
     它会**原样插入那张图片**，绝不会编内容；
   * 你觉得哪张识别得不对，可以选中它点「**标记为没把握**」；
   * 反过来，AI 判错了你也可以点「**改为用文字**」或「编辑正文…」改回来。

   > 在「设置 → AI」里勾上「允许把图片发送给 AI」并配一个支持视觉的模型
   > （例如通义千问 qwen-vl、智谱 glm-4v、OpenAI gpt-4o），
   > 这一步就变成**全自动、不用粘贴**。

6. **背单词**：每个书目都有「**单词书**」栏目。
   点「**添加单词**」，**只输入英文**（单词或短语，例如 `abandon`、`give up`），
   其余交给 AI 自动补齐：音标、词性、中文释义、例句（带翻译）、常用搭配。

   * 卡片**默认是折叠的 —— 只显示英文**，扫一眼就是一列生词；
   * **单击卡片任意位置**就展开看释义，再点一次折起来；
   * 「全部展开 / 全部折叠」一次搞定所有卡片；
   * 已经加过的词不会重复添加（忽略大小写）；
   * 搜索框里**中英文都能搜**（搜「放弃」能找到 `give up`）。

   > 想改哪张卡：**右键**它 →「编辑…」，或者「AI 补齐 / 重新补齐」。
   > 你手改过的内容**不会被重新补齐冲掉**（默认只填空白的字段）。
   >
   > **所有科目共用一个单词书** —— 卡片都放在
   > `<数据目录>/user data/wordbook/`，一个词一个文件。
   > 所以你在「英语1」里记的词，打开「英语2」甚至别的科目也能看到；
   > 也可以直接把这个目录拷给同学，或者用 Git 管理。

7. **让 AI 看某个文件**（讲义、课件、表格、代码……）：
   打开 AI 对话栏（右上角），点输入框旁边的「**附件**」按钮选文件，
   然后正常提问。它会**先把文件里的文字提取出来**，连同你的问题一起发给 AI。

   * 每份附件旁边都写着状态（`已提取 1234 字`、`图片（需要视觉模型）`……）；
   * **图片发不了**：AI 看不了图。它会明确告诉你，并建议你用上一条
     「图片提取为 Markdown」先把图转成文字；
   * 提取失败的文件（例如旧版 `.doc`）也会列出来并说明原因 ——
     **不会假装读过**；
   * 附件在你**点发送后就从输入区消失**（内容已经进了这次对话，
     之后追问还能看到），这样不会每一轮都重发全文。

5. **写学习目标**：双击 `Introduct.md` 打开，切到「编辑」模式写几句目标。
   例如：「掌握矩阵的秩、线性方程组解的结构；重点是一致性判定。」

6. **生成总结**：在书目页点「生成总结」。
   首次会提示配置 AI（见下一节）。生成完成后 `数学分析_summary.md` 会自动打开。

## 二、配置 AI

菜单「AI → AI 设置」，或菜单栏右上角「AI 对话 ▾ → AI 设置…」。

### 方式一：DeepSeek API（推荐，便宜、中文好）

1. 到 **`platform.deepseek.com`** 注册（注意是 `platform.` 不是 `chat.`），
   在「API keys」里创建 Key（形如 `sk-` 开头、35 个字符，**明文只显示一次**）。
2. 确认账户里有余额（新账号通常需要先充值；余额为 0 时报错很像「Key 无效」）。
3. 在设置页选择「DeepSeek API」，把 Key 粘到「API Key」框，模型保持 `deepseek-chat`。
4. 点「测试连接」，出现「连接正常」就成功了。
5. 点「保存」。

> ⚠️ 用浏览器打开 `https://api.deepseek.com/` 会显示 `Authentication Fails (governor)`，
> 这是官方设计如此，**不能用来判断 Key 好坏**。真正的验证只能靠软件里的「测试连接」。

### 方式二：GPT API

同上，选择「GPT API」，填 OpenAI 的 Key。
如果还想让 AI 看图（图片型 PDF 的内容），模型选 `gpt-4o` 这类支持视觉的。

### 方式三：本地 AI（断网/无 Key 时兜底）

选择「本地天禧 AI」，在「本地命令」里填写本机可用的命令行程序，例如：

```
tianxi --chat
```

约定：程序从**标准输入**读提示词，把回答写到**标准输出**。
如果本机程序的接口不同，见 `code\gwp\ai\providers\local_command.py` 顶部的说明。

### 方式四：网页版（不需要 Key）

选择「DeepSeek 网页版」或「GPT 网页版」。使用时软件会把提示词复制到剪贴板
并打开官网，你在网页里粘贴提问，得到回答后回到软件粘贴回答即可。

### 兜底顺序

设置里可填「兜底顺序」，例如 `deepseek_api, gpt_api, tianxi_local`。
主 AI 失败时会依次尝试，并在切换成功时弹窗提示你。

### 也可以不打开界面就配好 Key

```
cd "D:\Great White Planet\code"
venv\Scripts\python.exe -m gwp.cli key
```

回车后粘贴 Key 再回车，会自动保存并立即测通。Key 从标准输入读取，
**不会留在命令历史里**。另有 `key --show`（只看长度与首尾）、`key --clear`。

Key 存在 `data\else data\secrets.json`，不进代码、不进用户数据目录。

## 三、日常使用

### 新建一份笔记

「文件 → 新建 Markdown 文件…」（`Ctrl+Alt+N`）**只在书目页可用**，
文件会固定建在 `<书目>\notebook` 里（也就是「笔记」标签下）。

在首页或科目页这一项是灰的 —— 因为那时还没有选定是哪本书，
软件不会替你猜位置（否则文件会落到你不知道的地方，AI 总结也读不到它）。
如果记忆里想在哪儿建笔记：**先进书目，再新建**。

### 把几个科目收进收纳箱

科目多了以后，可以用**收纳箱**把相关的收在一起（例如「数学基础」装高等代数、
数学分析；「概率统计」装概率论、数理统计）。

1. 点首页右上角「**＋ 新建收纳箱**」，起个名字（例如"数学基础"）；
2. 把科目放进去，三种方式任选：
   * 直接把科目卡片**拖到**收纳箱卡片上；
   * 右键科目 →「**移入收纳箱…**」→ 点收纳箱名字；
   * 右键科目 →「移入收纳箱…」→「＋ 新建收纳箱并放入…」；
3. **单击收纳箱**即展开，主界面只显示箱内的科目；右上角点
   「**✕ 关闭收纳箱**」就回到「我的科目」总览。
4. 想把某个科目拿出来：**右键那个科目** →「**移出收纳箱：… → 最外层**」
   （只要科目在箱子里，这一项就会出现，总览里也能找到）；
   也可以单击选中后按 `Shift+Delete`，或右键箱子选「把箱内科目全部移出」。
   想换到别的箱子就选「移动到其它收纳箱 …」。
5. 按 `Esc` 或点「✕ 关闭收纳箱」退出箱子。

收纳箱卡片比普通科目卡片**多一圈边框**，一眼就能区分。
右键收纳箱可以重命名、换边框颜色、换卡片图片、清空、删除。

> **放心用**：收纳箱只是"分组记录"，不搬动任何文件。
> **删除收纳箱不会删除科目**，箱内科目会回到最外层。

### 调整卡片顺序

**直接拖动卡片**即可：

* 把**收纳箱**拖到**科目**上 → 箱子插到那个科目前面（左半边）或后面（右半边），
  于是箱子和科目可以交替排列；
* 把科目拖到**另一个科目**上 → 插到它前面或后面；
* **在收纳箱里拖动科目** → 调整**箱内顺序**（每个箱子各排各的）；
* 把科目从外面拖到**箱内的科目**上 → 进那个箱子，并插到目标位置；
* 把收纳箱拖到**另一个收纳箱**上 → 调整箱子之间的顺序；
* 把科目拖到**收纳箱卡片**上 → 是"收进箱子"，不是排序。

> 「科目拖到收纳箱」= **归类**；「收纳箱拖到科目」= **排序**。
> 想换箱子与科目的先后，拖**箱子**。

拖动时目标卡片边缘会显示一条黄色竖条，告诉你会插到哪里。
所有顺序都会保存下来，重启软件后依然保持。

### 整理文件：复制 / 剪切 / 粘贴

选中一个或多个文件（按住 `Ctrl` 或 `Shift` 多选），然后：

* `Ctrl+C` 复制 → 切到别的标签页（例如从「笔记」到「易错题」）→ `Ctrl+V` 粘贴；
* `Ctrl+X` 剪切 → 粘贴到别处 = 移动；
* 想粘到某个子文件夹：在该文件夹上右键 →「粘贴到此处」；
* 在资源管理器里复制了文件，回到软件里直接 `Ctrl+V` 也能粘进来。

同名文件不会被覆盖，软件会自动加序号（`笔记_1.md`）。
`book` / `error-prone` / `notebook` / `homework` / `others`
这些固定目录不允许剪切或复制（保护书目结构）。

### 记作业（校修课）

校修课的「作业」栏目和别处不一样：**「导入文件」按钮换成了「创建作业」**。

1. 进书目 → 切到「**作业**」标签 → 点「**创建作业**」；
2. 填四样东西（都可以只填一部分）：

   | 字段 | 例子 |
   | --- | --- |
   | **作业名称** | 第三章习题 |
   | **作业内容** | 课本 P80 第 3、5、7 题，要求写出完整推导 |
   | **DDL** | 勾「设置 DDL」后**用日历选日期**、**用上下按钮或滚轮调时分**；**不勾就是不设截止** |
   | **提交方式** | `https://course.example.edu/upload`（**只填网址**，可留空） |

   > 日期时间**不需要手打数字**：点右端的小日历图标弹出月历点一天；
   > 时分用输入框右边的**上下箭头**，或者把光标停在"时"或"分"上**滚鼠标滚轮**。
   > 好处是打不出非法日期，也不用在小格子里对准数字。

3. 确定后作业会变成一个文件夹，里面：
   * `homework.json` —— 记录 DDL 与提交网址；
   * `第三章习题.md` —— 你的作业内容，双击就能编辑；
   * 其它要交的文件（代码、截图）直接拖进这个文件夹。

   > **往作业里加附件**：双击作业进到它里面，顶部就会出现「**导入文件**」
   > （也可以把文件直接拖到作业那一行上，或右键文件夹 →「上传文件到「xxx」…」）。
   > 在作业栏目根目录时顶部是「创建作业」，进了作业里面就换成「导入文件」——
   > 因为新作业只能建在最外层。

   > **标签上的数字是"作业个数"**，不含每个作业内部的 `homework.json`
   > 与内容文件 —— 所以「作业 2」就是有 2 个作业，点进去正好 2 行。

   > **双击作业进到它里面**，就能看到这个作业文件夹里的**全部文件**：
   > 作业内容、老师发的图片、你放的附件都会列出来。
   > 其中 `homework.json` 是灰的、类型写着「作业信息」——
   > 那是软件记录 DDL 和提交网址用的，**别删它**（右键也没有删除入口）。

用起来是这样：

* **交作业**：点列表里的「**提交作业**」按钮 → 先弹一个框，写明  **这个作业在哪个文件夹**，还有「复制路径」「打开文件夹」两个按钮方便你把附件
  放进去；确认无误后点框里的「**提交作业**」才打开浏览器。
  （**它只打开网页，不会上传任何东西**。网址本身在列表里不显示 ——
  教务系统的网址太长，把鼠标停在按钮上就能看到完整网址。）
* **看截止**：列表多出「DDL」一列。
* **看交没交**：看**名字的颜色** ——

  | 状态 | 名字显示 | 整行底色 |
  | --- | --- | --- |
  | **已完成** | **绿色**「名字（已完成）」 | **没有底色** |
  | **未完成** | **红色**「名字（未完成）」 | 没有底色 |
  | **未完成** + 48 小时内截止 | 红色 | **浅黄** |
  | **未完成** + 已过期 | 红色 | **浅红** |

  > 一句话：**有底色的，就是"还没交、而且快到期或已经过期"的** ——
  > 先处理它们就行。交完之后底色会自动消失，名字变成绿色。
* **改内容或 DDL**：**右键作业** →「编辑作业…」；
* 双击作业是打开它所在的位置 —— 交作业请点「提交作业」按钮。

> 作业列表里**一个作业只占一行**，作业内部的 `homework.json` 和内容文件
> 不会铺出来碍眼；要打开它们就双击作业文件夹。

> 「提交方式」只接受 `http` / `https` 网址。填 `course.example.edu/x` 这种
> 漏了协议的，软件会自动补成 `https://`；填一段普通文字会被拦下并提示。
> **不填也完全可以** —— 比如老师当面收作业。

> 只有**校修课**有这套。自学课那段目录叫「练习」，仍然是普通文件夹。
> 作业和练习/教材一样**不参与 AI 总结**。

### 用「其它文件」+ 自建文件夹整理杂项

「其它文件」是留给**不属于教材/笔记/易错题/作业**的东西的，比如：

* 老师发的课件、讲义 PDF；
* 拍的板书照片、试卷照片；
* 从别处拷来的参考资料。

它的两个好处：**不参与 AI 总结**（放多少都不会影响总结质量）、
**可以自由建文件夹**。用法：

1. 进书目 → 切到「**其它文件**」标签；
2. 点「导入文件」把东西放进来，或者从资源管理器直接拖进来；
3. **右键任意条目 →「新建文件夹…」**，例如建 `第一章`、`模拟卷`；
4. **右键刚建的文件夹 → 再「新建文件夹…」**，就能继续分层，
   例如 `第一章\课件`、`第一章\作业答案`；
5. 新建的文件夹可以直接双击打开（在资源管理器里），
   也可以拖文件进去，或者用 `Ctrl+V` 粘进去。

> 「新建文件夹」和「新建 Markdown」在**每个标签页**都有 ——
> 想按章节拆分笔记，也可以直接在「笔记」里建子文件夹。

### 复习一门课

1. 首页点科目卡片 → 进入书目列表。
2. 点书目 → 直接落在「AI 总结」标签页（排在第一）。
3. 平时把课堂笔记丢进「笔记」，把做错的题丢进「易错题」。
4. 考前点「生成总结」，得到一份整合文档；
   如果想调整重点，先在「预览将总结的资料」里填「额外要求」。
5. 想换回上一次的总结：右侧「资料概览」→「恢复上一版总结」，
   或「版本管理…」里对比后再恢复。

> 右侧「资料概览」默认是**折起**的。需要看统计数字或那些快捷按钮时，
> 点页面上方的「**资料概览**」按钮展开，再点面板右上角的 ▾ 收起。

### 和 AI 讨论当前文档

1. 双击打开一份 Markdown。
2. 点右上角「AI 双栏」。
3. 第一次打开时软件会自动把这份文档发给 AI；之后你可以直接提问，
   例如「把第三节的推导补全」「帮我出 3 道同类型练习题」。
4. AI 不确定时会弹窗问你，回答后它会继续。
5. 满意的回答可以点「插入文档」放进正文。

### 随便问问（不读文件）

菜单栏**右上角的「AI 对话」按钮**，或按 `Ctrl+Shift+T`。
这个窗口不读取任何文件，适合问概念、梳理思路、写点东西。
想重新开始就点「新对话」（`Ctrl+N`）。

### 给软件换个背景

菜单「**查看 → 更改背景 → 选择背景图…**」（「设置 → 更改背景」里也有同一项）：

1. 点「导入图片…」选一张图（会被**复制**进图库，旧背景**不会删除**）；
2. 在列表里点任意一张即可切换，右侧预览；
3. 觉得外框太扎眼，把「蒙层深浅」往右拉；想更明显就往左拉；
4. 点「应用」。

背景图铺满整个工作区，内容块（卡片、面板、列表）浮在它上面；
页面顶部那一行会有一层淡淡的底色，保证标题和搜索框在任何壁纸上都看得清。
所以用深色或花的照片都不会影响看资料。
也可以直接把图片丢进 `D:\Great White Planet\data\else data\background`，
再打开这个窗口就能看到。不想用背景时点「不使用背景」——**图片仍然保留**，
随时能切回来。

### 导出 PDF 交作业/打印

打开文档 → 「文件 → 导出当前文档为 PDF…」（或 `Ctrl+P`），
或书目页「导出 PDF…」。

导出分两步（因为要先排版才知道有多少页）：

1. 填保存位置、纸张、边距，点「开始导出」；
2. 排版完成后弹窗问你：**是否加页码**、**导出哪些页**（默认全部）。
   页码可以写成 `1-3, 5`、`e`（最后一页）、`e-1`（倒数第二页）、`3-e`；
   写错了会当场提示并禁用确定按钮（例如 `2-1` 会提示「区间反了」）。

不想每次都弹窗，可在第一步取消勾选「导出前询问页码范围」。

书目页 →「版本管理…」→ 选历史版本 →
「与当前版本对比」看差异，或「恢复此版本」。
恢复时当前版本会先被备份，所以放心点。

## 五、常见问题

**Q：关掉窗口后软件还在跑？**

**是的，这是有意设计的。** 点右上角的 ✕ 只是把窗口**藏起来**，
软件继续在后台运行 —— 这样你下次用它就是**瞬间**出现的，
不用再等一次启动（启动要重建整个界面并预热扫描）。

把它叫回来（三种都行）：

* **双击右下角托盘里的星球图标**（最常用）；
* **再双击一次桌面快捷方式**（实测 0.3 秒）；
* 菜单「文件 → 隐藏到后台」是反向操作，不管用。

彻底退出：

* 右键托盘的星球图标 →「**完全退出**」；
* 或者菜单「**文件 → 退出**」。

> 第一次藏到后台时右下角会弹一个气泡说明，**只弹一次**。
> 不喜欢这个行为就去 **设置 → 常规**，取消勾选
> 「关闭主窗口时最小化到后台」，之后点 ✕ 就真正退出。
>
> 托盘万一不可用（极少见），软件不会静默退出，而是**最小化到任务栏**，
> 你仍然可以用上面两种方式唤回它。

**Q：双击快捷方式为什么有时弹"已在运行"？**
如果软件**在后台藏着**，双击快捷方式会直接把窗口叫回来，不弹框。
只有已有实例的窗口**是可见的**（你没找到它，或它在另一个虚拟桌面上）时
才会弹提示框 —— 框里写了怎么找回来。

**Q：日程栏太占地方 / 想让它宽一点？**

日程栏的宽度是**固定的**，只有两种状态：

* **完全展开**（380px，默认）—— 点面板右上角的 **»** 收起；
* **全部折叠**（只剩窗口右边一条竖直页签）—— 点那条页签顶部的 **‹** 展开。

所以**不能拖动**调节宽度（分隔条已经锁住了）。折叠后那条页签上
有竖排的「日程」字样，底部还显示还有几条没完成 —— 不会看不出那是什么。

> 折叠时上方的**日期/时间/天气条会一起收起来**（它属于日程栏）。
> 展开日程栏它就回来。

窗口变窄时，科目卡片会**自动换成更少的列**，不会躲到日程栏后面；
如果窄到连一列卡片 + 日程栏都放不下，**日程栏会自动折叠**把位置让出来
（状态栏会提示）。想展开点一下窄条上的 **‹** 即可 ——
变宽之后它**不会自己弹回来**，免得来回跳。

**Q：日程里点「打开」，为什么没弹出资源管理器？**

因为**改成在软件内跳转了**：会切到那本书目的**作业栏目**，并直接进入
那条作业的文件夹 —— 和你在软件里双击文件夹看到的一样。

想在资源管理器里看：在作业栏目里**右键 →「在资源管理器中显示」**。

**Q：双击快捷方式唤回时，窗口是黑的 / 软件直接崩了？**

这两个 bug 都**已经修好了**（它们其实是同一件事的两半）：

* **黑窗口**：以前是第二个进程直接调 Windows 的 `ShowWindow` 把窗口"显示"出来，
  但 Qt 不知道这件事，所以不重绘 —— 用户看到一片全黑。
  现在改成第二个进程只**留一个请求**，第一个进程自己用 Qt 把窗口显示出来。
* **直接崩溃**：曾经试过用"自定义 Windows 消息 + `nativeEvent`"来实现唤回，
  而那在 PyQt6 6.11 上必然崩溃（连只转发给父类都崩）。

现在的唤回**约 0.6–0.8 秒**出现，画面完整。如果还是不对，
看日志里有没有这两行：

```
已请求它把窗口唤回（未弹提示框）     ← 第二个进程写了请求
主窗口已从后台唤回                   ← 第一个进程自己显示了出来
```

**Q：任务栏图标还是 Python 的图标？**

任务栏图标由 **Windows 的应用标识**决定，不是窗口自己画的。
从源码运行时进程是 `pythonw.exe`，不设标识的话 Windows 会把窗口归到
Python 名下，于是显示蛇形图标。

现在已经设好了（启动时设置进程标识 + 给快捷方式写同一个标识），
任务栏应当显示**星球图标**。如果还是 Python 图标：

1. 先**退出软件**（托盘图标右键 →「完全退出」），再重新双击快捷方式；
2. 还不行的话，删掉桌面快捷方式，用软件菜单
   「**文件 → 创建桌面快捷方式**」重新建一个（旧快捷方式可能没有应用标识）；
3. 任务栏上的旧图标可能要**取消固定**之后才更新。

**Q：为什么我在本地建的文件夹，里面的文件没显示出来？**

因为**栏目里只显示这一层**。文件夹就是一行，**双击它进去**才看得到里面的东西。

> 早期版本会把子文件夹里的文件也铺出来（显示成「文件夹/文件」），
> 和文件夹平行排在一起 —— 那些行是**假层级**：删它删的是子文件夹里的文件，
> 很容易误操作。现在不会了。

只有右上角的「**最近**」列表例外：它按修改时间排，会列出深层文件。

**Q：怎么新建文件夹？建在哪儿？**

两个入口，落点都按「你现在在看哪儿」来定：

* **在列表空白处右键** ->「新建文件夹…」-> 建在**当前这一层**；
* **右键某个文件夹** ->「新建文件夹…」-> 建在**那个文件夹里面**；
* **右键某个文件** ->「新建文件夹…」-> 建在它**旁边**。

在「AI 总结」「简介」「全部条目」这几个虚拟栏目里，新建会**落到「笔记」**里
（菜单项上会写出来）。不能新建时菜单项是**灰的**，鼠标停上去有说明。

**Q：生成的 AI 总结在「AI 总结」标签页里看不到？**

这个 bug **已经修好了**（原因是软件内部的扫描缓存没失效，
刚写出来的 summary 文件要等下次启动才被发现）。

如果还遇到类似情况：点「刷新」按钮，或退出书目再进去。

**Q：md 预览里公式变成了一堆 `$\varepsilon$` 这样的源码？**

**已经修好了。** 现在公式会被**渲染成图片**再显示 ——
因为软件内的预览控件只支持很老的 HTML/CSS，不认识 LaTeX。

只支持常见的公式写法（上下标、分式、根号、上下限、希腊字母）；
**矩阵这类复杂排版排不出来**，会按纯文本显示（不会画错）。

**Q：「长庚知道」是什么？**

生成总结时勾上"文末加入「长庚知道」"，AI 就会在 PDF **最后面**多写几页
**知识点补充**（术语辨析、常见误区、知识联系、延伸），
**每一页左上角**都标着「长庚知道」。

它**只补充、不复述**你资料里的内容；位置固定在最末尾，
不会和你的资料页混在一起。AI 不可用时会自动跳过，**不影响资料页**。

**Q：AI 总结现在是什么？**

**一个合并好的 PDF**：``<书目>_summary.pdf``。

把「笔记」与「易错题」里的全部资料（外加简介）**合并成一个 PDF**：
PDF 每页转成图片、Word/PPT/Excel/Markdown 排版成页面图片。
生成结束后，你的电脑上**只会多出这一个文件** ——
中间用到的图片与临时文件都自动清掉了。

* 旧的 Markdown 总结（``*_summary.md``）会被**删掉**；
* 生成前的上一版会自动备份，可从「版本管理」退回；
* 如果提示"文件被占用"，关掉正在打开它的 PDF 阅读器再试一次即可。

**Q：怎么把 PDF、讲义这些资料合并到 AI 总结里？**

书目页顶栏点「**生成总结**」（或菜单「工具 → 生成总结…」）。

* 插入的是「**笔记**」与「**易错题**」里的全部文件（含子文件夹）；
* 每份资料都转成**页面图片**再合并进 PDF（保证版面和公式都在）；
* 图片集中放在 `data\else data\merged\<书目>\`，
  **不会动你的原始文件**；
* summary 会**整个重写**成"标题 + 资料"，旧版自动备份，
  可以从「版本管理」退回去；
* 点确认框的「取消」就什么都不做。

> **连续的多张图片之间没有间隙**；最后一张图与下面的文字之间只留一点点空间。

**Q：能让 AI 把不同文件夹的内容混在一起排吗？**

可以。点「生成总结」时会问你要不要
「**让 AI 按主题重排页序**」，勾上就行。

AI 会读**每页开头一小段文字**判断这页讲什么，然后把同一知识点的页排到一起，
于是不同文件夹的内容会真正交错穿插 —— 而不是"一个文件接一个文件"。

两点可以放心：

* **它只改顺序**，不增、不删、不改任何一页的内容；
* 只要 AI 的回答有漏页、多页或重复，就**整条不用**、退回原顺序；
  AI 不可用也一样。**绝不会因为排序出错而丢内容。**

不勾选就严格按文件顺序插入，**完全不调用 AI**（不发请求，不花额度）。

**Q：旧内容怎么办？**

每次生成都会把 summary 重写成"标题 + 资料图片"，
**旧内容会先自动备份**，在「版本管理」里，随时能退回去。

**Q：生成总结时 AI 会改写我的资料吗？**

**不会。** 内容是你文件的图片，原样插入，AI 不参与改写文字。
文档末尾那段「使用提示」也是固定文字，不是 AI 现编的。

**Q：双击 JSON 文件（比如作业信息）想用 VSCode 打开，但没反应？**

这曾经是一个 bug，**已经修好了**。原因是软件通过 `cmd /c` 去启动 VSCode 的
批处理入口，而 `cmd` 不会正确处理带空格的路径 —— VSCode 装在
`D:\VS Code\` 这种带空格的目录下时就 100% 失败
（报 `'D:\VS' is not recognized ...`），而软件还以为成功了，
所以表现为"点了没反应"。

现在改成直接启动 VSCode，不再经过 `cmd`。**如果还是打不开**：
看日志（`data\else data\logs\gwp.log`）里有没有「没有找到 VSCode」——
那说明软件没找到 VSCode，会退回内置的只读查看器。

**Q：在文件夹里删完文件，为什么跳回上一层了？**

这曾经是一个 bug，**已经修好了**。原因是刷新时只重画了各栏目的根目录，
没有重画"你当前所在的文件夹"，所以看起来像被弹回上一层
（其实标题和位置一直是对的，只有列表内容错了）。

现在在里面删除、重命名、导入、拖拽上传、新建文件夹**都会留在原地**。

**Q：作业名字写错了，怎么改？**

两个入口都行，效果一样（文件夹、作业信息、内容文件名一起改）：

* 右键那个作业 →「**编辑作业…**」，改「**作业名称**」栏；
* 右键那个作业 →「**重命名作业…**」。

改名的效果：

* **作业文件夹会一起改名**，里面的东西都跟着走；
* DDL 和提交网址**不会丢**；
* 新名字和别的作业重名时会被拦住并提示，不会覆盖别人的作业；
* 如果你自己改过作业内容那个 Markdown 的文件名，改名时**不会动它**。

**Q：我在资源管理器里改了文件，软件里怎么不变？**

现在**会自动变**了：软件一直盯着数据目录，最多 **约 6 秒**就刷新，
不用重启、也不用点刷新。

它**很省电**：窗口开着时约占单核 0.55%（整机 0.017%）；窗口关到后台或最小化时
**完全停止扫描**（0%），切回来时立刻补扫一次。

**Q：自动刷新太频繁 / 我想彻底关掉？**

改 `data\else data\config.json`：

```json
"ui": {
  "data_scan_interval_ms": 2000,     // 调大（如 15000）就更省；最小 1000
  "auto_refresh_on_change": false    // 设 false 就完全关掉
}
```

**Q：软件有时会"闪退"（窗口突然消失）？**

这个 bug **已经修好了**（原因：退出时还有后台线程在跑，
Qt 会直接中止整个进程 —— 所以日志里一个字都没有）。

现在退出前会**等后台线程结束**再关。副作用是退出可能多花一两秒
（在等预扫描或天气请求收工），这是刻意的：**宁可慢一点，也不要闪退**。

**Q：双击文件夹为什么不再弹出资源管理器了？**
现在**在软件内部进文件夹**：双击就进去，只显示它里面的东西，
标题会写明当前位置，顶部出现「↑ 上一层」按钮退回。
这样不会被打断，也不用在资源管理器和软件之间来回切。

确实需要资源管理器时，右键 →「**在资源管理器中显示**」依然可用。

**Q：双击 JSON 文件会怎样？**
**用 VSCode 打开**（方便直接改配置）。
如果你的电脑没装 VSCode，会自动改用软件内部的**只读查看器**打开，
不会弹到别的地方去。

其它文本类文件（.yaml、.ini、.py、.log 等）也是内部只读查看器打开，
里面有「用 VSCode 打开」「复制全部」「自动换行」几个按钮。
图片、PDF、Word 这些不是文本，仍然交给系统默认程序。



**Q：菜单里的「论坛 → 牢大CS」是什么？**
是你自己的论坛入口，点一下就会用**系统默认浏览器**打开
https://cs9.x-way.work/。

* 不需要配置，也不用登录软件；
* 地址写在配置文件里（orum.laoda_cs_url），想换域名改一行就行；
* 如果打不开（比如系统没设默认浏览器），软件会弹出提示并显示网址，
  你可以手动复制到浏览器。



**Q：首页右上角那块日期/时间/天气是怎么来的？要配置吗？**
不用配置，也不用 Key。软件启动时自动按网络定位所在城市（转成中文地名），
再从公开免费接口取一次天气，放在日程栏上方：

```
2026年10月9日 星期五                    16:39:36
中国 · 北京市                            25°C 阴
```

* **时间每秒自己走**，日期与星期也跟着日期变；
* **体感温度、湿度、风**把鼠标停在天气上就能看到（不占版面）；
* 天气**只在启动时拉一次**；抓取在后台进行，**不会卡住界面**；
* **没网也不打扰你**：显示「天气获取失败」灰色小字，不弹窗，其它功能照常用；
* **不想联网就在「设置 → 界面」里取消勾选「显示天气」**
  —— 那样只显示日期时间、完全离线；连日期时间都不想要就取消「首页显示日期与时间」。

**Q：怎么记"下周三要交学费"这种和课程无关的事？**
首页**右侧就是日程栏**，点「**＋ 新建日程**」填名称和时间（时间可以不填），
它会和其它日程一起按时间排好。不需要挂到某个科目下。

**Q：作业会出现在日程栏里吗？**
会，**自动出现**，不用手动登记。日程栏把两样东西合在一起按 DDL 排序：

| 来源 | 从哪来 |
| --- | --- |
| **作业** | 你在校修课里创建的作业 |
| **其它日程** | 你点「＋ 新建日程」加的待办 |

每条右边都有「**完成**」按钮：作业点完会把 `done` 写进它的 `homework.json`；
其它日程点完就标为已完成。完成后条目**划线变灰并排到最后**
（不勾「隐藏已完成」还看得见，也能取消完成）。

左边那条彩色竖线是状态：**红=已过期、黄=48 小时内截止、绿=已完成**。
顶部还写着「待办 N / 共 M」，一眼知道还剩几件。

**Q：建科目时类型选错了，能改吗？**
能。**自学课与校修课可以随时互相切换**：

* 右键科目卡片 →「**修改类型…（当前：自学课）**」，确认即可；
* 也可以在「编辑名称/类型…」对话框里一起改。

两者目录结构**完全相同**，所以切换**不会移动或删除任何文件**，
只是「练习」这个栏目会改叫「作业」（或反过来）。

**日记不能改成普通科目**（反过来也不行）—— 它的目录是
`AI summary` / `AI diary` / `my diary` / `else diary`，与普通科目差别太大。
这种情况下菜单里那一项是**灰的**，鼠标悬停能看到原因。
真要换，请新建一个目标类型的科目，再把文件手工搬过去。

**Q：首页看不到我放进 data 的科目？**
确认文件夹直接位于 `data\user data\subjects` 下（不要多套一层），然后点首页「刷新」。
如果软件里显示不了，用「工具 → 打开数据目录」核对实际位置。

**Q：导入的文件去哪了？**
复制到了该书目的对应分类目录，例如「笔记」标签导入的文件在
`<书目>\notebook` 下。原文件不会被删除。

**Q：AI 报「未配置 API Key」？**
在「AI → AI 设置」里填写并保存（或 `gwp.cli key`）；也可以设置环境变量
`DEEPSEEK_API_KEY` / `OPENAI_API_KEY` 后重启软件。

**Q：浏览器打开 api.deepseek.com 显示 Authentication Fails，是不是 Key 坏了？**
不是。那个地址不接受浏览器匿名访问，官方设计如此。
判断 Key 好坏要看软件里「测试连接」的结果；如果测试也失败，
按提示逐条排查（Key 是否配到了别的提供方、是否粘漏了字符、
是否用的是中转站却填了官方地址、余额是否为零）。

**Q：生成总结要很久？**
资料越多越久。软件会自动分块提炼再合并，进度窗口里能看到当前阶段，
也可以随时取消（取消不会破坏已有的总结）。

**Q：生成失败了，我的总结会不会没了？**
不会。写入顺序是「先生成 → 再备份 → 最后替换」，
AI 失败时磁盘上什么都不变；即使替换后不满意，也能在「版本管理」里恢复上一版。

**Q：扫描件 PDF 生成出来是图片，能不能转成文字？**
当前版本刻意不猜内容（准确性优先）。如果需要文字，
可以先用 OCR 工具转成文本再放入 `notebook`。

**Q：`.doc` / `.ppt` / `.xls` 导入后说明无法解析？**
这是 2003 旧格式，请先用 Office 或 WPS 另存为 `.docx` / `.pptx` / `.xlsx`。

**Q：聊天记录怎么没了？**
按需求设计，关闭软件时会清空全部聊天记录。
如果希望保留，可在「设置 → AI」里取消勾选「关闭软件时清除所有 AI 聊天记录」。

**Q：导出的 PDF 里页码是「8 / 12」，但我只导了 3 页？**
这是刻意的：页码显示的是**原文档中的页号**，方便引用与对照，
所以从 12 页里抽第 8 页出来，页脚仍然是「8 / 12」。

**Q：换了背景，旧图会被删掉吗？**
不会。新图复制进图库时文件名只递增数字（`桌面.png` → `桌面_1.png`），
旧图一直保留，随时可以在「设置 → 主界面背景」里切回去。

**Q：删除科目 / 书目会不会手滑删掉？**
不容易。删除要走两道确认，而且有这几层保护：

* 弹的是**警告框**，「删除」按钮必须**主动点击**；
  **默认按钮是「取消」—— 直接按回车不会删除**；
* 框里会写明这个科目有几本书目、约多少个文件；
* 里面**有内容**时会**再问一次**「真的要删除吗？」；
* 删除是**移入系统回收站**，可以从回收站还原。

如果回收站不可用（系统限制、目录过大等），弹窗会**明确写「将永久丢失、无法还原」**，
不会让你误以为还能找回。点「详细信息」还能看到真实路径和各目录的文件数。

> 想更保险的话：定期把 `data\user data` 整个复制一份到别处，就是最可靠的备份。

**Q：能不能同时开多个窗口看不同资料？**
可以。双击 Markdown 默认在新窗口打开（可在设置里改成主窗口内切换）。

**Q：软件启动慢？**
第一次启动会做一次全量扫描。之后有缓存，并且默认开启「启动时后台预扫描」。
如果科目特别多，可以在「设置 → 启动与集成」里调整。

**Q：双击快捷方式没反应（或提示"已经在运行"）？**
说明软件已经开着了——同一个数据目录只允许一个主窗口。
请在任务栏（或 `Alt+Tab`）里找到已经打开的窗口。
如果确实没有窗口却一直提示，删除 `data\else data\instance.lock` 后重新启动即可
（这个文件只记录正在运行的进程号和窗口句柄，删掉是安全的）。

**Q：我用 Win11 的多桌面，在第二个桌面启动时提示"软件已在另一个桌面上运行"？**
这是有意的。软件只会出现在打开它的那个桌面上，不会在每个桌面都冒出来，
也不会在第二个桌面再开一份。想切过去看它，可以：

* 按 `Win + Ctrl + ←/→` 在当前桌面之间切换；
* 按 `Win + Tab` 打开任务视图，点那个桌面上的软件窗口；
* 或者直接点提示框里的「切到那个桌面」按钮。

**Q：怎么卸载？**
删除 `D:\Great White Planet` 整个目录即可。
如果要保留资料，只删 `code` 目录；另外在「设置 → 启动与集成」里关掉开机自启、
删除桌面快捷方式。
